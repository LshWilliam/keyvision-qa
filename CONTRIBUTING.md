# Contributing

1. Open an issue describing the defect, dataset rights, or proposed experiment.
2. Create a focused branch and keep generated data, checkpoints, credentials, and logs out of Git.
3. Add or update tests for behavior changes.
4. Run `ruff check .`, `ruff format --check .`, `mypy keyvision scripts`, and `pytest`.
5. State the provenance and license of every new dataset, weight, and visual asset.
6. Submit a pull request with commands actually run, results, limitations, and migration notes.

Do not include employer or customer material unless public redistribution is explicitly authorized.
By contributing original code, you agree to license it under the repository's MIT License.
